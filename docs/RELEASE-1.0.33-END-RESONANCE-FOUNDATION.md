# Mirage Projector 1.0.33 — End Resonance Foundation

Internal implementation note. End Resonance remains a discovery-oriented 1.1 feature and should not receive an explicit public recipe/tutorial disclosure.

## Delivered

- `SpecialResonanceProfile` separates non-PU catalysts from Projection Cores.
- Field and Prism explicitly expose End Resonance capability; Compact/Display/Wide/Tall/Table/Wall/portable reject it.
- Dragon Egg is accepted physically only by compatible fixed chassis and remains a real, non-consumed item.
- Insertion captures a persistent complete projector-facing restore snapshot without embedding the catalyst.
- Removal restores the saved source/settings/snapshots/staging state.
- Save/reload preserves the restore snapshot.
- Normal source/settings mutation is blocked while resonance owns the chassis. TURN OFF stays attemptable and retains the established event feedback.
- GUI switches to a resonance status/read-only presentation.
- Field renders fixed 2×3 planar End-style geometry following chassis facing.
- Prism renders fixed 2×3×2 volumetric End-style geometry.
- Resonance render bounds are independent of normal Scale/Lift/Float/Rotation.
- Creative clone strips the unique catalyst and uses the suspended projection state.
- Chassis upgrade recipes reject packed projectors while a special catalyst is installed.
