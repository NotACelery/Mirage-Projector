# Mirage Projector — next-chat handoff after dev.52

## What changed

This wave is a focused visual pass after dev.51 QA.

### Improved Cores
- The rotated middle shell is no longer a rescaled cube that can protrude past the outer shell.
- It is now a rotated wireframe-style frame built from thin cuboids and intended to keep its borders visible.

### Crying Obsidian buds / cluster
- The growth logic from dev.51 is retained.
- Only the visuals were changed: the textures were repainted to look closer to Amethyst growth silhouettes while preserving the Crying Obsidian palette.
