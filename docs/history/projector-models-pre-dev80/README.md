# Pre-dev.80 legacy projector models

These six JSON files are the old canonical projector block models that were replaced in `0.1.0-dev.80`.

They are stored under `docs/history` intentionally and are **not runtime assets**. Minecraft/NeoForge must not load them. The accepted `*_alt` comparison models from dev.79i were promoted to the canonical IDs in dev.80.

Canonical IDs retained in runtime:

- `mirage_projector`
- `mirage_display`
- `mirage_field_projector`
- `wide_mirage_projector`
- `tall_mirage_projector`
- `mirage_prism`

The temporary `*_alt` registry IDs/assets were removed from the active source line.
